# Лабораторная работа 9 — Advanced Login

Продолжение лабораторной 8 (`web9`). Методичка: `../methodical/Ch9.odt`.
Ruby 3.4.11, Rails 8.1.4, Bundler 4.0.21; SQLite в development/test.

## Запуск в Windows

В терминале из папки `web9`:

```powershell
chcp 65001
bundle install
rails db:prepare
rails dartsass:build
rails server -p 3009
```

Открыть http://localhost:3009. Регистрация: `/signup`, вход: `/login`.
Создайте аккаунт через форму регистрации — вход произойдёт автоматически.
Для выхода откройте Account → Log out. Остановка сервера: Ctrl+C.

База этой лабораторной: `storage/development.sqlite3` внутри `web9`.
Пользователи из базы `web8` автоматически не переносятся.

После изменения SCSS выполните `rails dartsass:build` либо запустите
`rails dartsass:watch` в отдельном терминале. На Windows Puma и тесты
работают в одном процессе. Для Docker предусмотрен `compose.yaml`
с портом 3000 вместо 3009.

## Проверки

```powershell
rails test
bundle exec rubocop
```

Реализованы разделы 9.1–9.3: случайный remember token, bcrypt-хеш в базе,
постоянные cookies и восстановление входа без временной сессии.
На форме входа появился флажок **Remember me on this computer**.
Если он снят, постоянные cookies удаляются; если установлен — вход
восстанавливается при следующем открытии браузера. Выход удаляет cookies
и аннулирует токен в базе; повторный выход безопасен.

Дополнительно выполнено упражнение 9.3.2: session token позволяет
аннулировать скопированные сессии после выхода. Как в методичке,
на пользователя хранится один remember digest: новый запомненный вход
заменяет предыдущий токен, а выход аннулирует сессии этого пользователя.

Cookies user_id зашифрованы, cookies с токеном имеют HttpOnly и SameSite=Lax;
в production используется Secure. В базе хранится только хеш токена.
При автоматическом входе после регистрации постоянные cookies не выдаются.

Ссылки Users и Settings остаются заглушками до главы 10.
В production унаследованы HTTPS, Puma и PostgreSQL; развёртывание
на хостинге не выполнялось. Проверки описаны в [docs/lab9.md](docs/lab9.md).
