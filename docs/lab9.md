# Лабораторная 9 — Advanced Login

Методичка: `methodical/Ch9.odt`. Основа — отдельная копия лабораторной 8.

| Раздел | Реализация |
| --- | --- |
| 9.1.1 | миграция `remember_digest`, виртуальный `remember_token`, `SecureRandom.urlsafe_base64`, bcrypt-хеш |
| 9.1.2 | постоянные cookies, зашифрованный user_id, восстановление current_user при отсутствии временной сессии |
| 9.1.3 | forget удаляет хеш, выход удаляет cookies и сбрасывает сессию |
| 9.1.4 | безопасный повторный выход; отсутствие remember_digest возвращает false |
| 9.2 | флажок Remember me; снятый флажок удаляет ранее выданные cookies |
| 9.3.1 | тесты входа с запоминанием и без него, соответствия токена хешу, неуспешной аутентификации |
| 9.3.2 | тесты восстановления входа, подмены токена, удалённого пользователя и отозванного токена |
| Упражнение 9.3.2 | session_token на основе remember_digest аннулирует ранее выданные сессии после forget |

Дополнительно проверены два независимых клиента: новый сеанс получает только
постоянные cookies и восстанавливает вход; копия тех же cookies после выхода
больше не позволяет войти. В базе хранится хеш, а не исходный remember token.
Cookies отмечены HttpOnly и SameSite=Lax, в production — Secure.

Локальные проверки: 59 тестов, 236 проверок, без ошибок и падений.
Стили собираются Dart Sass. Инструкция запуска находится в README.

Как в методичке, используется один remember_digest на пользователя.
Новый запомненный вход заменяет прежний токен. Выход аннулирует связанные
с этим хешем сессии в других браузерах. Управление списком устройств
потребовало бы отдельной таблицы и в этой главе не реализуется.

Публикация исходного кода в GitHub не является развёртыванием приложения
на хостинге. Проверка закрытия реального браузера вручную не выполнялась;
переход к новому сеансу покрыт интеграционным тестом.
